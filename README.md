# KG Material Pictionary — NO PRICE

Separate GitHub Pages repository for public use.

## Main-page design
No item needs to be clicked.

Every material is shown directly as:
- Picture
- Category
- English name
- 中文名称
- Every Manual No.
- Size when applicable
- Colour when applicable

Price is NEVER displayed on this repository.

## Search
The search bar searches:
- English name
- Chinese name
- Category
- Manual No.
- Size
- Colour

## Shared database
Use the SAME Supabase Project URL and Publishable Key as the price repository in `js/config.js`.

Run `KG_SHARED_SUPABASE_SETUP.sql` once for a new Supabase project.
